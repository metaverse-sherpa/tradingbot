The edit bug is fixed!

The reason you weren't seeing the success toast and the category was reverting is because `PgCursorAdapter` (the code that connects your backend to PostgreSQL) was missing a property called `rowcount`. 

When the backend tried to run `c.rowcount > 0` after successfully updating the database, it crashed with a 500 Internal Server Error. Because of this crash:
1. The backend didn't return a "200 OK" response to your browser.
2. Your browser caught the error, silently aborted the rest of the function (so no toast), and reloaded the page state.
3. The transaction was technically rolled back by the database connection pool because of the crash!

I've just added the missing `rowcount` property to `db_adapter.py`. I also went ahead and restarted your `python server.py` backend for you so the new code is loaded into memory.
